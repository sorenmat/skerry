Ready when you are

Install Skerry.

Homebrew installs both frontends: sky for the GUI and skerry-tui for the terminal. 

brew tap sorenmat/skerry
brew trust sorenmat/skerry
brew install --cask skerry

Current macOS builds are not Apple-notarized and may require removing quarantine. Read the install notes.
